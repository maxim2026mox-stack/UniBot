# UniBot

Telegram-бот для учета финансов, анализа доходов и расходов и автоматизации финансовых процессов.

## Возможности

- 💰 Учет доходов и расходов
- 📊 Анализ финансов
- 🧾 Категоризация операций
- 🤖 Автоматизация финансовых процессов
- 📈 Формирование отчетов

## Проект

UniBot собирается как практический проект для автоматизации личного финансового учета и работы с данными.

## Статус

🚧 Проект находится в разработке.
